LED, Tlačitka a Bzučiak #

LED diódy #

Na module sú zapojené 3 LED diódy, ich anódy sú pripojené cez rezistor 1k k napájaciemu napätiu +5V. Katódy sú pripojené k pinom mikrokontroléra, dióda sa rozsvieti pri stave piny LOW.

LED

Arduino

Nucleo-64

D1

D13

PA5

D2

D12

PA6

D3

D11

PA7

D4

D10

PB5

Poznámka

K pinu PA5 je doske Nucleo-64 pripojená zelená LED, ktorá ovlyvňuje stav LED D1. Na module Nucleo-64 je možné ju odpojiť zrušením prepojky SB21.

Programovanie #

Príklad riadenia LED

Program rozsvietenia a postupného zhasnutia LED

from pyb import Pin
from time import sleep

d1 = Pin('PA5', Pin.OUT)
d2 = Pin('PA6', Pin.OUT)
d3 = Pin('PA7', Pin.OUT)
d4 = Pin('PB6', Pin.OUT)

d1.off(); d2.off(); d3.off(),  d4.off()

sleep(0.5)
d1.on()

sleep(0.5)
d2.on()

sleep(0.5)
d3.on()

sleep(0.5)
d4.on()

Tlačítka #

Na module sa nachádzajú tri tlačítka A1…A3 pre všeobecné použitie a resetovacie tlačitko mikrokontroléra.

Programovanie #

Príklad vyvolania prerušenia tlačitkami 
from pyb import Pin
s1 = Pin('A1', Pin.IN)
s2 = Pin('A2', Pin.IN)
s3 = Pin('A3', Pin.IN)

s1.irq(lambda p:print('S1', s1.value()))
s2.irq(lambda p:print('S2', s2.value()))
s3.irq(lambda p:print('S3', s3.value()))

Bzučiak #

Bzučiaka je pripojené k pinu D3 pomocou spínacieho tranzistora.

Bzučiak

Arduino

NUCLEO-64

LS1-3

D3

PB3

Programovanie #

Príklad spustenia a zastavenia bzučiaka 
import pyb
from time import sleep

b=Pin('D3', Pin.OUT_OD)

# spistenie bzuciaka
b.on()
sleep(0.5)

# zastavenie bzuciaka
b.off()
